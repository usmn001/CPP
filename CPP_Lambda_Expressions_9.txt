C++11 introduced Lambda expressions.
Prior to C++11 we had : Function Objects (Classes containing functions) , 
                        Function Pointers.

Problem  : Function objects and function pointers is that compiler cannot inline these functions for efficiency.
           These function objects and function pointers cannot be tested because they are defined far away from where they are used.
           Every function object has a overloaded operator function : void operator()(int x)

            							       }

The compiler generates unnamed function objects from lamda expressions.

Example of Lambda Expression Based Upon Previous scenario : 

std::vector<int> vec {1,2,3,4};
std::transform(vec.begin(), vec.end(),vec.begin(),[](int x){return x*10});

So a lambda expression syntax : [](type variable){operation to perform};                         
                            Where : [] is capture list, what kind of elements we want to capture
                                    () parameters passed to function 
                                    {} code performing some operation 
                                    
-----------------------Structure of A Lambda Expression-------------------------

[] () -> return_type specifiers {}

Where : "[]" 		Capture list, what kind of elements we want to capture.
        "()"            Parameters passed to function.
        "return_type"   Just like a function return type can be skipped and compiler will try to deduce it.
        "specifiers"    Optional specifiers can be mutable and constexpr
        "{}"            Code performing some operation. 

-------Stateless Lambda Expressions---------

Stateless lambda expressions have empty capture list i.e with parameter []

Example 1 : [] () {std::cout<<"Hi";};

Example 2 : [] () {std::cout<<"Hi";}();  // Here this lambda expression is calling function object as discussed previously.

Example 3 : [] (int x, int y) {std::cout<<x+y;};

Example 4 : auto l = [] (int x) {std::cout<<x;};    // Assigning lambda expression to a variable.
           l(10);   // displays 10   ,Just like function object, we are calling lambding expression.
           l(100);  // displays 100  ,Just like function object, we are calling lambding expression.

Example 5 :  int x {10};                         // This variable value will not be used as our lambda has empty capture list
             [] (int x) {std::cout<<x;}(100);    // Displays 100 as we are initializing variable x by value 100 just like function object.

---------------------mutable keyowrd-------------------------------

If we want to modify a capture  type in lambda expression then we can use mutable keyword in lambda expression as : 

Example 8 : 

       int x {100};

        auto l = [x] () mutable {             // Now we can modify local variable copy, local variable outside of lambda expression block will retain itś original value of 100
                x += 100;
                std::cout << x << std::endl;     // Displays 200
        };
        
       l();            // Displays 200
       cout<<x;        // Displays 100

Example 9 : We can also pass the type by reference as : 

 int x {100};

bool in_between(const std::vector<int> &nums, int start_value, int end_value) {
    bool result {false};
    result = std::all_of(nums.begin(), nums.end(), [start_value, end_value](int value) {
        return value >= start_value && value <= end_value;
    });
    return result;
}

class Password_Validator2 {
private:
	std::vector<char> restricted_symbols {'!','$','+'};
public:
	bool is_valid(std::string password) 
	{
		return std::all_of(password.begin(), password.end(), [this] (char character)      // 1st algorithm method
		{
			return std::none_of(restricted_symbols.begin(), restricted_symbols.end(), [character] (char symbol)      // 2nd algorithm method 
			{
				return character == symbol;
			});
		});
	}
};

In the above code we are using nested algorithms both returning values by using lambda expressions.
