STL is a : Powerful Library collection of reusable,adaptable,generic classes and functions.
           Implemented using C++ templates.
           Implements common data structures and algorithms.
           developed in 1994.

STL  :     Assortment of commonly used containers.
           Known time and size complexity.
           Tried and tested-Reusability.
           Consistent,fast and typesafe.
           Extensible.

Elements Of the STL are : Containers collection of objects or primitive types (array,vector,deque,stack,set,map,etc)
                          Algorithms functions for processing sequences of elements from containers(find,max,count,accumulate,sort,etc).
                          Iterators Generate sequences of elements from containers( forward,reverse,by value, by reference,constant, etc).


Example :             #include<algorithm>         //allows us to work with stl algorithms
                      #include<vector>
                      
                      int main()
                      {
                      
                      
                      std::vector<int> v {1,5,3}; 

                    
                      // STL sort function : Sorts the elements in the vector similar to qsort macro we use sort function of stl:
                      
                      std::sort(v.begin(),v.end()); // Where v.begin() and v.end() are iterators pointing to where 1st and last element of vector


                      // STL reverse function : Sorts the elements in reverse order of the vector we do :
                      
                      std::reverse(v.begin(),v.end()); // Where v.begin() and v.end() are iterators pointing to where 1st and last element of vector
                      

                      // STL Accumulate function : for summing the elements of vector

                      int sum{};  
                         
                      sum=std::accumulate(v.begin(),v.end(),0 )   // Where v.begin() and v.end() are iterators pointing to 1st and last element of vector, third parameter is for starting running sum

                       return 0;
                       }

--------------------Generic Programming With Function Templates----------------------------


C++ Template is : A Blueprint
                  There are function and class templates.
                  Allows plugging in any data type.
                  Compiler generates appropriate function/class from blueprint 


----------Example : Defining function with template

template <typename T>      // We can also write it as template <class T>, here we have used class instead of typename

T max(T a, T b) 
{

return (a>b)? a:b;

}

The above code will be compiled by C++ compiler but it won´t generate any code as we need to provide information for the types.


To use the above function we need to provide typename at the time of function invoking i.e. max<int>(a,b);

Sometimes we don´t even need to specify the typename as compiler automatically figures out the type by looking into the passed parameters types i.e. max(a,b).


The above template function supports all the types provided that specific type supports the operator > as with our defined classes we need to provide this operator overloaded definition.


-----------------Example : Function With different template types

We can also have multiple template parameters with different types i.e

template<typename T1, typename T2>
void func(T1 a, T2 b) 
{
cout<<a<<" "<<b;
}

To use the above function we need to provide typename at the time of function invoking i.e. max<int,double>(a,b);

Sometimes we don´t even need to specify the typename as compiler automatically figures out the type by looking into the passed parameters types i.e. max('A',12.4).

----------------------------------------------Sequence Container-Deque----------------------------------------			    
			    
https://en.cppreference.com/w/cpp/container/deque
			    
Header file to include in the code : #include<deque>

Deque like vector container is dynamic in size but elements are not stored in continous memory in fact they are a block of memory linked together.

Deque size is handled automatically.

Deque allows direct element access (constant time).

Deque has rapid insertion and deletion at the front and back (constant time).	

Insertion and removal of elements in deque is of linear time.

All iterators are available but become invalid when deque changes size.		    
			    
			    
Deque syntax : std::deque<type> deque_name{val1,val2,val3};			    
			    
			    
Examples : deque<int> d{1,2,3,4,5,6};			    
	   deque<int> d1{10,100};
           deque<string> stooges { string{"Larry"}, "Moe", string{"Curly"} };

---------------------------------Sequence Containers - Forward List-----------------------------			    
			    
STL forward list : #include<forward_list>,  std::forward_list;

                   Singly linked list,
                   Available to us in the namespace of std as std::forward_list , can be traversed in one direction.
                   Sequence Of Containers 
                   Non contingous in memory.
                   No direct access to elements.
                   Rapid insertion and deletion of elements  anywhere in the container (constant time).
                   less overhead than stl list.
                   Reverse iterators are not available. Iterators invalidate when corresponding element is deleted.		    
			    
			    
Declaration Syntax : forward_list<Type> list_name {val1,val2};			    
			    

Common Methods Available : 

list_name.max_size();

list_name.front();


Person p1{"Larry",18};

forward_list<Person> list_name;

list_name.push_front(p1);
list_name.pop_front()

list_name.emplace_front("Moe",24);    // adds a object person to front of list.


forward_list<int> l{1,2,3,4,5};

auto it = find(l.begin(),l.end(),3);

l.insert_after(it,10);   	      // Outputs : 1 2 3 10 4 5
l.emplace_after(it,100); 	      // Outputs : 1 2 3 100 10 4 5

l.erase_after(it);                    // erases the 100, 1 2 3 10 4 5

l.resize(2);                          // 1 2 , Resizes our current list to a size of 2

l.resize(5);                          // Outputs :  1 2 0 0 0

#include <iostream>

class Person {
    friend std::ostream &operator<<(std::ostream &os, const Person &p);
    std::string name;
    int age;
public:
    Person() : name{"Unknown"}, age{0} {}
    Person(std::string name, int age) 
        : name{name}, age{age}  {}
    bool operator<(const Person &rhs) const {
        return this->age < rhs.age;
    }
    bool operator==(const Person &rhs) const {
        return (this->name == rhs.name && this->age == rhs.age);
    }
};

---------------------Container Adaptors - Stack----------------------

STL Container adaptor stack is equal to C style (LIFO structure) stack however we don´t need to define and implement a stack using arrays or linked list . 
STL provides its implementation of stack through vector,list or deque itś upto us what we choose from(vector,list,deque).
Deque is the default implementation of container adaptor stack.
All operations (PUSH,POP,SIZE) made available as built in methods saving a lot of effort.
Not iterators are supported for stack container as all operations occur on top of stack.

stack is known as container adaptor because it can be adapted and implemented through different STL Containers vector,list,deque 
deque is default implementation of stack.

---------Stack Initialization--------------
To use stack in our code just do this : #include <stack>

std::stack<int> s;

std::stack<int,std::vector<int> >s1; // stack implementation using vector container

std::stack<int,std::list<int>> s2;   // stack implementation using list  container 

std::stack<int,std::deque<int>> s3;  // stack implementation using deque container 


Example : 
#include <iostream>
#include <stack>
#include <vector>
#include <list>

template <typename T>
void display(std::stack<T> s)
{
std::cout<<"[";
while(!s.empty())
{
T elem =s.top();
s.pop();
std::cout<<elem<<" ";
}
std::cout<<"]"<<std::endl;
}

int main()
{
std::stack<int> s; 
std::stack<int,std::vector<int> > s1;    
std::stack<int,std::list<int> >  s2;     
std::stack<int,std::deque<int> >  s3;

for(int i:{1,2,3,4,5})  // Ranged base for loop iterating over an array
s.push(i);            // Pushes the element at end
display(s);

s.push(100);
display(s);

s.pop();              // Pops the element from front i.e. top of stack  
s.pop();
display(s);
std::cout<<"size"<<s.size()<<std::endl;

s.push(10);
display(s);

s.top() = 100;
display(s);
return 0;
}

First in First Out (FIFO) data structure.
Similar to stack , queue is also an adaptor contianer that can be implemented either through list or deque.

-----------------------Container Adaptor : Priority Queue-------------------

https://en.cppreference.com/w/cpp/container/priority_queue.html

std::priority_queue       // It is just like stack and queue container adaptors

Allows insertion and removal of elements in order from the front of container.

Elements are stored internally as a vector by default. (A data strucure heap is used behind the scenes different from heap (new,delete) and malloc(),free()

Elements are inserted in priority order (largest value will always be at the front)

No iterators are supported.

top : accesses the top element

push : inserts element and sorts the underlying container

pop : removes the top element i.e. pop the largest element as it has highest priority.

empty : checks whether the container adaptor is empty

size : returns the number of elements
